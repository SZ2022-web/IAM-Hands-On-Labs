# IAM Hands-On Labs

Practical Identity and Access Management (IAM) projects using Microsoft Entra ID.

This portfolio documents my hands-on practice with user lifecycle management, password administration, security groups, directory roles, and audit logs. Each lab includes explanations and screenshots showing the work performed.

## Lab Directory

| Lab | Project | Skills Practiced |
|---|---|---|
| 00 | [Entra ID User Lifecycle](Lab-00-Entra-ID-User-Lifecycle/) | User account administration and lifecycle fundamentals |
| 01 | [Employee Lifecycle](Lab-01-Employee-Lifecycle/) | Onboarding, department transfers, group membership, offboarding, and sign-in validation |
| 02 | [Password Reset](Lab-02-Password-Reset/) | Administrator password reset, user password change, and audit verification |
| 03 | [Group Management and RBAC](Lab-03-Group-Management-and-RBAC/) | Security groups, direct Directory Readers assignment, permission observations, and role removal |

## Skills Demonstrated

- Creating and managing test user accounts
- Enabling and disabling accounts
- Updating employee profile information
- Adding and removing security group members
- Supporting employee onboarding, transfers, and offboarding
- Resetting passwords and reviewing password-change events
- Assigning and removing Microsoft Entra directory roles
- Reviewing sign-in and audit logs
- Documenting configuration changes and observed results
- Removing temporary access after testing

## Tools Used

- Microsoft Entra admin center
- Microsoft Entra ID
- Sign-in logs and audit logs
- GitHub and Markdown
